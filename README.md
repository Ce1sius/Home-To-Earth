# 星火归航 · 火星归航战役

《星火归航》是一款 2D 火星卡牌经营游戏。你从迫降点的一个领队起步，救助伙伴、分配工具、建立补给，再到北缘高地寻找航标。三份航标能拼出归航路线，最终由领队带上补给登舱。营地自动化、第三位队员、周边勘探和邻站互助都可以按自己的节奏安排。

## 克隆并运行

在准备存放游戏工程的目录运行以下命令。公开仓库可直接克隆。

```sh
git clone https://github.com/Ce1sius/Home-To-Earth.git
cd Home-To-Earth
```

1. 安装与你的操作系统对应的 Godot 4.5.1 标准版。工程使用 GDScript 和 GL Compatibility 渲染器，开发与成品验证使用 4.5.1。工程文件保留了原有的 4.6 特性标记。[Godot 4.5.1 官方下载](https://godotengine.org/download/archive/4.5.1-stable/)
2. 在 Godot 项目管理器选择「导入」，打开仓库根目录的 `project.godot`。首次等待编辑器导入图像、字体等资源并生成本机缓存。
3. 按 **F5** 运行游戏。在主菜单选择「开始新游戏」，完成首轮打捞并救助勘探员。有存档时可以选择「继续游戏」。

接手开发的同学和 AI 可先阅读项目背景、已实现的范围、关键文件和验证步骤，再查看仓库的开发约定。[AI 开发交接](AI_HANDOFF.md) · [开发约定](AGENTS.md)

最新火星版策划、课堂汇报及历史稿见 [设计资料](docs/design/README.md)，各阶段的操作画面见 [实机截图](docs/playtests/README.md)。

### 同学如何一起改

仓库所有者在 GitHub 的 **Settings → Collaborators → Add people** 邀请同学的 GitHub 用户名。同学接受后就能把开发分支推回本仓库。[GitHub 协作说明](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/repository-access-and-collaboration/inviting-collaborators-to-a-personal-repository)

以修改高地雷达为例，先在本地执行 `git switch main`、`git pull --ff-only` 和 `git switch -c feature/highland-radar`。修改并试玩后，用 `git status` 核对文件，提交本次改动，再执行 `git push -u origin feature/highland-radar`。最后从 GitHub 发起目标为 `main` 的 Pull Request，让队友能看差异、试玩并合并。

| 操作 | 效果 |

| 左键点击队员卡 | 选择要派工的队员 |
| 顶部队员栏 | 持续显示全部队员；点击定位营地、高地或外出的队员 |
| 左键点击目标或物资卡 | 查看配方、物资说明或当前状态 |
| 拖工具卡到队员卡 | 把营地唯一的工具交给这名队员，当前及后续的打捞、采集、制造速度提高 25%。也可先选队员，再点击工具卡分配 |
| 右键空地 | 移动当前队员，并解除原有岗位 |
| 右键地图目标 | 就地打开任务列表，选择单次工作或设置岗位；显示配方、耗时及缺料原因 |
| 把队员卡拖到采集点或生产设施 | 设置持续岗位，缺料时保留工作等待补给 |
| 把队员卡拖到其他目标 | 执行建设、研究、救助等单次任务 |
| 把物资卡拖到对应的目标卡上 | 为当前队员安排需要这项物资的任务 |
| 拖动闲置的居住舱、温室、工作台或研究站 | 在地图空地重新布置；青色预览表示可放，重叠或占用时说明原因 |
| 高地地图左上「浅层雷达」 | 布设探针、比对回波圆并标记埋藏点。网格支持点击，也可用方向键移动、Enter 落针或标记 |
| 地图左上「周边勘探」 | 首批口粮收获后开放，选择派出的队员与回收路线 |
| 物资栏上方「工作安排 / 生产订单」 | 统一选择当前区域的生产、研究、建设、交易或运输；生产可设置岗位、批数与库存目标 |
| 右侧阶段任务下方的按钮 | 打开目标地点的任务列表；可定位当前任务与补给缺口。限时互助有独立按钮，可以分别查看 |
| 物资栏上方「暂停 / 恢复自动采冰」 | 装配采冰机后控制设备，暂停期间保留批次进度 |
| 顶部的地图按钮 | 在已抵达的两个区域之间切换视野 |
| 顶部倍速按钮或数字键 1 / 2 / 3 | 在 1 倍、2 倍、4 倍速之间切换，队员、设备、用餐与委托共用游戏时间 |
| 空格 | 暂停或继续时间，暂停时可以查看、派工、设订单 |
| Esc | 打开暂停菜单，可保存、重开或返回主菜单 |

拖起队员或物资时，会标出可接受的目标；移动到目标上可预览投入与产出。青色目标可安排，黄色目标可建立缺料等待的岗位，文字同时说明原因。开工时物资向工位移动，已预留材料显示在工位卡上；完成后产出提示飞向库存。动画只展示结果，不影响材料结算。暂停菜单可开关操作音效、减少动态效果。

右侧任务沿着「勘察 → 救助 → 首批补给 → 恢复通信 → 高地航标」推进。循环泵、扩建、第三名队员、能源自动化和周边勘探属于可以自行穿插的发展路线。蓝图研究站右键菜单与工作安排使用相同的任务来源，新找到的采样蓝图不会遮住通信或循环泵研究。拖入物资时，会优先选择当前队员可以执行的配方，已经完成的研究不会挡住后续试制；放下前仍可查看实际选择。

初始库存为 6 份应急口粮和 1 套简易工具，着陆区有自带 2 个床位的应急居住舱。第一次右键残骸可以拆舱体取得 3 残件，或抢救补给箱取得 1 残件和 4 口粮。两条路线都足够搭建温室，前者利于尽早扩建，后者留给救助与野外勘探的口粮更多。勘察阶段的残骸和矿点各能回收一次。完成勘察后，带 1 份口粮救助勘探员，随后可同时派一人用残件搭建温室，另一人去冰脉采水冰。建成后把队员拖到温室设置持续岗位，每轮消耗 1 份水冰、产出 3 份口粮。水冰耗尽时温室会等待补给，冰脉可反复采集。右键温室后选择「培育口粮」只生产一批，也可以选择「设岗位」。队伍扩充后开始每分钟按留在营地的人数消耗口粮，耗尽时普通作业变慢，温室仍可运行。

温室产出首批口粮后，地图上出现研究站、工作台、曙光勘探站和周边勘探入口。用 1 份矿样和 1 份残件研究维修蓝图，再在工作台用 2 份残件加工结构件。电路可通过以下两种常规途径取得，也可从周边勘测车一次性回收。

- 向曙光站交换。每份电路需 2 份口粮，或 3 份残件。曙光站消耗自己的物资生产电路，可在站点卡上查看库存。
- 在工作台自制。蓝图解锁后，选择「制造电路」，消耗 1 份结构件和 2 份矿样。

## 设施布置与周边勘探

四类营地设施出现后，可按住卡牌拖到空地调整位置。布置按网格吸附，不额外消耗材料，已有升级保留。设施有队员正在工作或等待时需要先停止工作；放置不能覆盖其他卡牌、队员或目的地，也会为后续出现的点位留出空间。队员之后会前往新工位，实际行走距离随布局改变。资源点与接驳设施保持固定；当前尚未实现任意新建设施、多座同类设施或绕障寻路。

收获首批口粮后，点击「周边勘探」。每处地点仅能选择一条路线，探索结束后另一条不再开放。窗口会暂停营地时间，关闭后恢复之前的运行状态。下列数值按空背架计算。耗时为基础作业时间，不含前往出发点的步行，队员状态会影响实际速度。

| 地点 | 路线一 | 路线二 |
| --- | --- | --- |
| 散落货舱 | 1 口粮、18 秒 → 5 残件 | 2 口粮、30 秒 → 2 结构件 |
| 冰层裂隙 | 1 口粮、24 秒 → 5 水冰 | 2 口粮、30 秒 → 6 矿样，健康降低 12；健康低于 40 不可出发 |
| 废弃勘测车 | 2 口粮、27 秒 → 2 电路 | 2 口粮、1 残件、36 秒 → 精密采样蓝图 |

队员先前往居住舱出发点，开工时预留补给，随后离开营地卡牌区域。途中无法承担其他任务，也不重复扣营地用餐口粮；另一个队员可以继续生产。顶部队员栏持续显示外出进度，点击后可在详情中召回，也可从勘探窗口召回。召回取消本次探索、退回未结算补给，并恢复原有营地岗位，地点仍可重新选择；成功返回后才发放奖励。当前召回即时完成，三处地点均为固定内容。

带回采样蓝图后，在研究站选择「试制精密采样器」，消耗 2 残件和 1 电路。完成后，矿脉每批矿样由 2 增加到 3，单次采集与持续岗位都生效。因此勘测车的选择是立即得到建设零件，或投入更多材料提高后续产量。

### 野外整备与补给巡线

首批温室收获后，从「周边勘探 → 野外整备」打开托盘。把材料卡拖入三个格子，或逐张点选。材料次序任意，点击格中的材料可退回。凑齐图纸后点击「组装」，再将模块装上背架。模块可重复使用，一趟带一件。从派遣到返营期间锁定装备。

| 模块 | 组装材料 | 带上它的作用 |
| --- | --- | --- |
| 保温补给箱 | 2 残件、1 水冰 | 勘探和巡线少带 1 份口粮，最低仍需 1 份 |
| 绞盘 | 1 结构件、2 矿样 | 野外作业速度提高 25%。深入裂隙的健康损失从 12 降至 4，山脊巡线从 8 降至 2 |

完成任意一处遗址后，可从勘探面板下方选择补给巡线。冰沟适合给温室补水，山脊适合在营地缺建材时回收零件。出发界面会按当前背架显示实际补给、基础作业时长和受伤代价。

| 路线 | 空背架出发 | 返营所得 |
| --- | --- | --- |
| 沿冰沟收取补给 | 2 口粮，约 29 秒 | 3 水冰、2 残件，无受伤 |
| 上山脊回收测绘桩 | 2 口粮、1 水冰，36 秒，出发至少需 40 健康 | 3 矿样、1 结构件，损失 8 健康 |

两条巡线共享出发窗口，每趟成功返营 90 秒游戏时间后可再次出发。召回会退还该趟预留补给，可立即改派。已完成全部三处遗址的旧营地也能参加巡线。

## 营地发展与三人分工

首批收获后，可以按下面的顺序改善营地，也可以直接准备通信信标。主线任务不会把这些升级显示为必经门槛。

1. **取得循环泵蓝图**。首次电路交易时，曙光站会同时分享蓝图。也可在研究站选择「研究循环泵蓝图」，投入 2 份矿样和 1 份残件。
2. **完成试制**。选择温室，再选择「试制循环水泵」，投入结构件、电路、水冰各 1 份。试制完成后，每份水冰产出的口粮从 3 份增加到 5 份。已有温室岗位的队员可以临时承担试制，结束后继续种植。
3. **准备床位**。用 2 份残件扩建应急居住舱，床位从 2 个增加到 3 个。也可以提前扩建。
4. **接纳农艺师**。循环泵试制后出现合作申请，选择扩建后的居住舱，投入 2 份口粮接纳。队伍增加为三人，同时增加口粮消耗。

| 队员 | 特质与专长 | 分工示例 |
| --- | --- | --- |
| 领队 | 野外经验，采集速度 +15% | 维持水冰库存，临时外出勘察 |
| 勘探员 | 精细维修，制造与建造速度 +25% | 按批数加工结构件、搭建设施 |
| 农艺师 | 温室经验，种植速度 +35% | 维持口粮库存 |

队员详情显示健康、体力和士气。获救的勘探员带伤加入，健康低于 90 时工作速度降低 10%。待命和休整会恢复健康，连续劳动消耗体力，短缺口粮会降低士气。体力低于 20 时，在下一批开工前自动休整，到体力 85、健康 95 后恢复工作。也可选中队员主动安排休整，原岗位会保留。

「工作安排 / 生产订单」提供四种方式。

- **持续岗位**：反复进行同一工作，直至停止或被临时任务打断。
- **指定批数**：例如制造 3 批结构件，完成后解除订单。材料按每批开工预留。
- **目标库存**：例如水冰维持 6 份、口粮维持 15 份。达到目标就等待，库存消耗后恢复，完整批次可能略超目标。
- **单次任务**：只完成一批生产，或一次研究、装配、维护。能源研究和工程固定使用这种方式，窗口内显示地点与材料投入。

临时任务结束后自动归岗。跨区域外出会保留营地岗位，在外期间停止执行，返回后恢复。外出时「召回」退回本次补给并保留岗位；在营地选择「停止行动并解除岗位」会清除岗位并退回未完成批次的材料，已完成的产出保留。首次勘察时两个基础点各采集一次；救助队员后即可重复采集，允许先囤积材料再搭温室。口粮卡显示距离下次用餐的时间与预计消耗。

曙光站从开局就在后台生产，即使尚未接触也会消耗自己的口粮与残件。完成两次交易后，若该站有口粮、残件、电路各 1 份且交易工位空闲，会投入这些库存扩建制造间，将电路生产周期从 28 秒缩短到 20 秒。缺原料时会停产，可在站点详情查看库存与扩建状态。

## 邻站限时互助与营地护理

首次收获后运行 45 秒，曙光站开始发来互助请求。之后依次轮换净水系统检修、补给车整备、联合地质测绘。每次有 **150 秒**，从通知出现到完成交付计时，包含队员步行、休整和作业时间。完成或逾期后等待 90 秒，再出现下一种请求；当前采用固定轮换。

选择队员，右键曙光站，或从「工作安排」选择带「互助」的任务。每次只能完成下列两种方案中的一种；缺料时仍能看到该方案的投入和回礼。普通电路贸易继续开放。窗口与空格暂停会停止期限计时，可以先比较方案、规划人手。

| 请求 | 方案一 | 方案二 |
| --- | --- | --- |
| 净水系统检修 | 4 水冰 → 2 电路，基础作业 12 秒 | 2 残件 + 1 结构件 → 1 电路 + 3 口粮，14.4 秒 |
| 补给车整备 | 5 口粮 → 2 结构件，12 秒 | 2 结构件 + 1 电路 → 8 残件 + 4 口粮，15.6 秒 |
| 联合地质测绘 | 6 矿样 → 2 电路，14.4 秒 | 3 矿样 + 1 结构件 → 5 口粮 + 1 电路，15.6 秒 |

队员到达后预留交付物资，完成后才拿到回礼。另一名队员可继续维持温室和采集。成功交付会关闭该次请求的两个方案，恢复队员原岗位。逾期不会扣额外罚款，会退回尚未交付的物资并自动归岗；手动停止会退回物资并解除岗位，请求在期限内仍可重选。回礼独立于邻站常规贸易库存；交付的口粮、残件和结构件会进入邻站对应库存。请求、剩余时间与交付进度都会保存，退出期间不扣时间。

救助勘探员后，居住舱右键菜单和「工作安排」开放 **营地护理**。选择需要恢复的队员，消耗 1 口粮、1 水冰，基础护理 12 秒，恢复健康 30、体力 35，两项最高为 100。健康已满且体力不低于 90 时不能安排，避免无意义消耗；无需先等疲劳队员自行休整。护理完成后恢复原岗位，也可以继续选择不耗材料的休整。

**首次完成任意互助后，曙光站分享护理方案，健康恢复提高至 45。** 这使合作回报不只是一批材料：可以把生产余量投入合作，再用改善后的护理恢复危险勘探归来的队员。当前是补给护理机制，尚未实现疾病、医生职业或完整医疗系统。

## 能源与自动化补给

完成循环水泵试制后，底部「工作安排 / 生产订单」开放能源工程。选中营地队员，再从工作内容选择任务。能源蓝图提供两条路线，任选其一，完成后即可装配设备。

| 步骤 | 地点 | 投入 | 结果 |
| --- | --- | --- | --- |
| 研究能源蓝图 | 蓝图研究站 | 2 矿样、1 电路 | 解锁储能组与采冰机 |
| 交换能源蓝图 | 曙光勘探站 | 4 口粮、1 结构件 | 同样解锁能源设备，物资实际交给邻站 |
| 组装太阳能储能组 | 着陆舱残骸 | 2 结构件、1 电路 | 白天发电，储电上限 40 |
| 装配自动采冰机 | 浅层冰脉 | 2 结构件、1 电路 | 无需队员驻守，通电后自动补充水冰 |

太阳能储能组装好后，可直接选中残骸卡清理太阳能板；采冰机装好后，冰脉卡显示设备状态和当前批次进度。原有手工采集仍可进行，自动化也可与通信修复、高地探索并行推进。

- **发电与负载**：清洁太阳能板在日照下每秒发电 2，夜间依靠蓄电。结构件、电路制造有电时速度额外提高 25%，用电 1/秒；缺电时恢复手工作业速度。自动采冰用电 1/秒，供电只够一个负载时优先工作台。
- **自动采冰**：每累计通电工作 20 秒产出 2 份水冰，库存达到 6 后等待，用掉库存后自动恢复。按整批产出，因此可能达到 7 份。缺电、手动暂停或维护时不消耗采冰用电，也不丢失已有批次进度。
- **设备维护**：每批采冰降低 5 点设备状态，降至 0 后停机。派队员用 1 份残件维护，恢复到 100。太阳能板会逐渐积尘，发电量按板面清洁度下降；清理同样消耗 1 份残件，清理期间停止发电，蓄电仍可使用。
- **昼夜与沙尘**：物资栏上方显示电量、天气倒计时和采冰机状态。沙尘提前 30 秒预警，持续 30 秒，期间太阳能输出降至通常的 25%；抵达时额外降低 25 点板面清洁度。可提前储备水冰和蓄电，或暂停采冰，把电量留给制造。

当前环境周期采用加速原型参数：储能组建成后启动，120 秒一轮，其中日照 80 秒、夜间 40 秒；沙尘每 240 秒一轮，首次在第 150 秒预警、第 180 秒抵达。这是用于试玩调校的经营节奏，不代表真实火星昼夜时长。暂停会停止环境和生产，切换地图则继续运行。

## 恢复通信与高地探索

修复信标需 1 份结构件和 1 份电路。信标上线后，轨道站会发来北缘高地的旧测绘站坐标。选择信标卡，可以花 2 份口粮派队员勘察，也可以随行运送 1 份结构件和 1 份电路作为前哨物资。

队员抵达后，顶部会开放地图切换。两个区域共用一条时间轴，左键可选当前区域的队员派工。高地的旧测绘站可回收一份航标记录，前哨物资到货后可架设通信前哨。两项完成后，前哨会自动将航标记录上传至轨道站。队员可从高地接驳点返回迫降地，返程补给已计入出发的口粮。

物资在队员抵达作业点并开工时预留。停止行动会退回尚未用完的物资。前哨只有在货物抵达后才能开工。

跨区运输与周边勘探使用同一套外出规则：步行去出发点时仍在营地用餐，正式出发后不再重复扣营地口粮。途中可从顶部队员栏查看与召回，不能直接改派营地工作或休整。抵达高地后，点击该队员即可切换视野；工作安排会列出当地勘察、前哨建设和返程任务。

取消运输返回该次行程的出发点。因此取消从高地返回营地的行程时，队员仍留在高地，可再次安排返程；不会直接跳过运输，也不会获得额外退款。

### 高地浅层雷达

第一次有队员抵达北缘高地，就能点击左上角「浅层雷达」，也可以右键旧测绘站启动仪器。雷达暂停游戏时间。水冰透镜和坠落货箱各有一张 9 列 × 6 行的局部测区图，每局重新确定位置，两区的探针单独记录。

1. 在两个相隔较远的格心各放一枚探针。圆周经过所有符合这枚探针读数的位置，目标必须同时落在两个圆上。
2. 如果还有两个可能的交点，把第三枚探针放在偏离前两枚连线的一侧。也可以撤回最后一枚，换个位置重测。
3. 点击「标记埋藏点」，再点击判断出的格心。若未命中，读数会保留，可直接再试。命中后返回高地地图，把当地队员卡拖到出现的地点，或右键下达发掘指令。

| 测区 | 一次发掘的收获 | 可用去向 |
| --- | --- | --- |
| 水冰透镜 | 5 水冰、2 矿样 | 给温室供水，或作为研究、制造材料 |
| 坠落货箱 | 2 结构件、1 电路 | 运回营地后可用于前哨运输、阵列设备或归航舱 |

发掘物资先放在高地接驳点，地图下方可见暂存数量。安排当地队员返回迫降地，出发时会装载当时货架上的全部物资，抵达后进入营地库存。途中召回会把货物放回高地。另一名队员在发车后挖出的物资留待下一趟。每处仅能开挖一次，测区进度、货架和途中货单均可保存。

## 第二份归航航标

首份航标上传后，高地出现「旧测向阵列」，右侧任务转为「恢复第二份航标」。先返回迫降地，选择一条途径获得校准蓝图。

| 途径 | 操作位置 | 投入 | 结果 |
| --- | --- | --- | --- |
| 与曙光站合作 | 曙光勘探站，或把结构件拖到该站 | 2 份结构件 | 曙光站接收维修材料，分享校准蓝图 |
| 自行研究 | 蓝图研究站 | 3 份矿样、1 份电路 | 根据首份航标推导校准蓝图，耗时较长 |

两条途径解锁同一能力，任选一条即可。获取蓝图期间，曙光站仍可用口粮交换电路。蓝图完成后恢复原有的两种电路报价。

备齐 **2 份口粮、2 份结构件、1 份电路**，选择通信信标，再选择「运送阵列设备」。也可将结构件或电路拖到信标上派送。队员与设备实际抵达高地后，右键「旧测向阵列」修复并校准，前哨会上传第二份航标。另一名队员可以留在营地维持生产。返程仍由「高地接驳点」安排。

## 最后一份航标与起航

第二份航标同步后，自选一条路线取得最后的坐标。

| 地点 | 交付或操作 | 所需物资 |
| --- | --- | --- |
| 北缘高地 · 旧测向阵列 | 派当地队员直接测定信号，基础作业约 29 秒 | 2 口粮、2 矿样 |
| 迫降地 · 曙光勘探站 | 用加工好的组件交换测绘记录，基础作业约 11 秒 | 2 结构件、1 电路 |

完成其中一种后，在着陆舱残骸投入 3 结构件和 2 电路整备归航舱。此时仍可继续经营。准备好结束本局时，让领队回到迫降地，在通信信标选择「领队登舱归航」，携带 3 口粮和 2 水冰。登舱作业完成前可取消退料。

起航后可回看这次旅程的航线、用时、人数、互助和勘探记录。主菜单的「查看归航记录」恢复这次结果。「开始新游戏」与暂停菜单的「重新开始」都要明确选择「替换进度」才会重开。

## 保存与继续

- 开始新游戏时创建进度，之后每 30 秒游戏运行时间自动保存，关键任务完成后也会保存。
- 暂停菜单可手动「保存进度」，返回主菜单或正常关闭游戏窗口也会保存。
- 主菜单的「继续游戏」恢复库存、蓝图、区域、队员位置、正在进行的工作、运输物资和邻站生产计时。退出期间不计算离线生产。
- 旧版本存档会自动补齐新系统的初始状态，保留原有航标和在途货物。旧存档中的持续种植任务会转为温室岗位。新存档同时保存队员状态、剩余批数、库存目标、循环泵和邻站扩建进度。
- 能源蓝图、设备、电量、清洁度、磨损、未完成采冰批次、开关和天气计时也会保存。载入沙尘预警不会重复扣除清洁度。
- 设施位置、探索选择、途中进度、预留补给和采样器试制同样保存。当前数据版本为 8，兼容版本 1 至 7。托盘中的材料、已组装和装载的模块、完成巡线次数与下次出发时间均随营地保存。会保存工具持有人、末份航标来源、归航舱与最终记录。版本 4 的设施位置、探索成果和能源进度原样保留，新增互助从等待首个请求开始，存档文件名保持不变。
- 互助类型、剩余时间、后续轮换、完成与逾期次数、护理效果及未完成交付都可恢复。载入不重复扣除预留物资，也不会重置有效期限。
- 当前使用一个存档位。选择「开始新游戏」或「重新开始」会替换已有进度。
- 存档位于 Godot 用户数据目录的 `campaign_v1.json`，macOS 默认是 `~/Library/Application Support/Godot/app_userdata/星火归航/`。写入先使用临时文件，完成后再替换已有存档。

## 导出 macOS 应用

在 Mac 上使用 Godot 4.5.1，通过「编辑器 → 管理导出模板」安装匹配该版本的官方模板。从仓库根目录运行以下命令可生成通过成品验证的通用应用。将 `--godot` 改为本机 Godot 可执行文件的位置，并为 `--output` 选择一个尚未存在的 `.app` 路径。

```sh
python3 tools/export_macos.py --godot /Applications/Godot.app/Contents/MacOS/Godot --output "../星火归航-0.5.0.app"
```

已有单独下载的匹配模板时，可追加 `--template /path/to/macos.zip`。脚本从导出的游戏包运行两条归航路线、野外整备、高地雷达和两份 0.4.0 测试存档的迁移，核对 Apple Silicon 与 Intel 架构、素材许可与本地签名后，再写入目标位置。日常开发按 F5 即可运行。

## 验证

首次克隆时先运行 `godot --headless --path . --import`。用 `godot --headless --path . --script dev_skills/godot-gdscript/assets/check_scripts_compile.gd` 检查脚本能否载入。下列游戏流程测试中，多数临时存档的路径写成 macOS 的 `/private/tmp`。Windows 和 Linux 上也可通过编辑器运行游戏。在这些系统执行涉及存档的自动测试前，需将测试文件中的临时路径适配到本机。

首次导入后，可以从本目录运行流程检查。`opening_flow.gd` 覆盖两条主线路线及保存继续。`camp_life.gd` 从菜单开始验证三人营地、两条循环泵路线、岗位与订单、暂停规划和邻站扩建。`industry_flow.gd` 继承完整营地流程，再验证两条能源路线、装配退款、自动产出、沙尘、维护与菜单继续。`power_rules.gd` 检查电量守恒、夜间停机、负载分配、库存上限、设备磨损和天气存档。`work_rules.gd` 验证中途取消退款、疲劳休整、外出归岗和实际技能效率。存档检查包含旧版迁移、损坏文件和写入失败。所有检查使用临时存档，与玩家进度分开。

`board_play.gd` 专门验证实际右键选单、鼠标拖放预览、材料反馈与取消退款。加 `-- --force-fail` 会有意返回失败，用于验证测试框架。使用显示窗口并传入已存在的截图目录时，会记录操作画面。当前主要支持桌面鼠标与键盘；不声明完整手柄或移动端支持。

`frontier_play.gd` 从菜单开始操作设施拖放、重叠拒绝、新位置建造、两组探索路线、途中菜单存档与继续、召回退款、风险损伤和蓝图试制；也检查探索文字未超出所在卡片。`frontier_rules.gd` 补充版本 3 电网迁移、非法布局与探索记录、预付口粮和有限奖励检查。原生窗口验证会同步移动鼠标来测试 Godot 的实际落点，因此运行期间请暂勿操作游戏窗口。

`integration_play.gd` 从开局串联设施布置、温室补给、探索蓝图、其他研究、工具试制、通信修复与高地往返，验证统一入口、队员定位和菜单焦点。`integration_rules.gd` 专门检查跨区途中不重复用餐、无法远程派工、读档后召回退款与恢复库存岗位。

`aid_play.gd` 从主菜单实际操作救助护理、采集与种植、限时交付、菜单存档与继续、危险勘探后的护理和逾期归岗；`--components` 改走维修件交付路线，`--compact` 检查较小窗口。`aid_rules.gd` 验证六种交付的实际投入产出、互斥结果、同帧到期、途中退款、自动归岗、护理上限以及版本 4 迁移。加 `-- --force-fail` 可验证故意失败会以非零状态退出。

`tests/gear_patrol_play.gd` 从主菜单开始，实际拖卡制作两种装备，分别完成遗址与两次巡线，覆盖取消派遣、出行读档、实际扣料与受伤。加 `-- --compact` 可在小窗口验证。

`tests/radar_play.gd` 从新营地进入高地，验证鼠标和键盘布针、误判重试、实地拖卡开挖，以及召回、读档和最终入库。`tests/radar_rules.gd` 检查两个测区、错峰返运、单次入库和版本 7 迁移。
