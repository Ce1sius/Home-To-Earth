# 《星火归航》策划与课堂汇报

课堂反馈后，团队将主题调整为火星探索与合作开发，保留卡牌堆叠、人员分工、蓝图、生产和归航。接手策划从现行 Word 开始，准备演示时直接编辑现行 PowerPoint。核对游戏里已能操作的内容，请参阅[运行说明](../../README.md)和[策划案对照](../../策划案对照.md)。

## 现行材料

- [游戏策划案 V0.2 · 火星探索与开发](星火归航游戏策划案V0.2_火星探索与开发.docx)记录世界观、玩家定位、核心交互和后续构想。文档版本 V0.2 与可玩程序版本各自独立。
- [火星探索与开发版汇报](星火归航游戏策划汇报_火星探索与开发版.pptx)按世界观、目标玩家、玩法、特色与独特性、开发困难组织内容。校园封面、游戏参考截图与中文演讲备注保存在可编辑的演示文稿中。

## 编辑依据与参考图

- [早期逐页文字与讲稿](authoring/authored-content.json)包含 18 页的概念提案文本。[五部分结构布局](authoring/slide-plan.json)列出 22 页的章节、参考页与文本。两份 JSON 均对应历史稿。
- [参考图来源](authoring/参考图片来源.md)列出 Stacklands、《环世界》《文明 VI》《戴森球计划》的商店页面与截图出处。游戏实际采用的美术、字体与许可见[素材清单](../../assets/ASSETS.md)。
- [Word 修订脚本](authoring/update_doc.py)和[幻灯片修订脚本](authoring/update_ppt.mjs)保留从旧主题调整为火星主题时的逐项编辑。前者依赖 Python 与 `python-docx`，参数为新 DOCX 路径。后者依赖 Node.js 与 `@oai/artifact-tool`，参数为新输出目录，可生成候选 PPTX 及逐页预览。日常修改可直接使用 Word 或 PowerPoint，游戏运行只需 Godot。

仓库中的共享副本使用项目组署名，已清除 Office 文件属性里的个人作者、最后编辑者以及历史布局文件中的个人姓名。讲稿、参考图与来源标注均保留。
